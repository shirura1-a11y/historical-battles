# Audio provenance and permissions

No downloaded recordings, sample libraries, existing compositions or external audio
assets are used. `produce.py` synthesizes original sine-wave music, percussion,
seeded noise footsteps/clashes, a tonal turn cue, and retreat pulses using only
Python's standard library. These are stylized effects, not field recordings.

The project dedicates the procedural score, synthesis code and generated audio to
the public domain under CC0 1.0 Universal, to the extent applicable law permits.
Commercial use, modification and redistribution are permitted without attribution.
No third-party audio attribution or paid subscription is required.

CC0 legal terms: https://creativecommons.org/publicdomain/zero/1.0/legalcode
This is a project dedication, not a claim that a third-party stock library was checked.

Tools: Blender (GPL), Python (PSF), FFmpeg (build-dependent LGPL/GPL), Noto CJK
fonts (SIL Open Font License 1.1). Those tool licenses do not require a rendered
video to be distributed under the tools' source-code licenses. Noto fonts are
installed by the OS package manager and are not redistributed in this repository.
